# 📌 TL;DR

**The problem.** In pixel-space Transformers, one patch grid fixes everything
at once: how finely the input is read, what each token predicts, and how many
tokens join global attention. Finer detail therefore inflates the quadratic
global stage directly. Yet not every output role needs global communication:
low-frequency structure benefits from global exchange, while high-frequency
detail can be modeled locally.

<p align="center">
  <a href="assets/allocation.pdf">
    <img src="assets/allocation.png" width="90%"
         alt="JiT patch-grid tokenization versus SpecSlot allocation into spatial anchors and spectral slots, with global carrier attention and local slot attention">
  </a>
</p>
<p align="center"><em>N = W × K separates spatial anchor density W from spectral subdivision K. Global attention uses one image carrier per anchor plus the context states.</em></p>

**The method.** SpecSlot makes token roles explicit:

- **Spectral allocation:** each spatial anchor expands into K slots; every slot owns a fixed, disjoint band of DCT coefficients.
- **Carrier routing:** only the lowest-frequency slot of each anchor joins the global stage; all slots interact locally within their anchor.
- **Dual-basis decoding:** a spectral prediction and a local spatial correction are combined in pixel space.

**The result.** SpecSlot gives a controllable quality–compute frontier. On
ImageNet-512, SpecSlot (W256/K4) reaches **9.14 FID at 135.64 GFLOPs**: 2.84
FID below the FLOPs-matched JiT-CM control at 3.9% lower cost, and within
0.69 FID of JiT-B/16 at 38.2% lower cost. In text-to-image generation, it
reaches **62.21 DPG-Bench**, surpassing JiT-B/8 (61.15) at 40.6% lower cost.

# 🛠️ Setup

Use one Python 3.10 environment for training and evaluation on Linux with an
NVIDIA GPU:

```bash
conda create -n specslot python=3.10 -y
conda activate specslot
python -m pip install "uv==0.12.21"
uv sync --locked --extra eval
source .venv/bin/activate
```

Use `uv sync --locked` when evaluator dependencies are not needed.

# 🖼️ ImageNet

Prepare the standard ImageFolder layout:

```text
/path/to/your/ImageNet/
├── train/<class>/*.JPEG
└── val/<class>/*.JPEG
```

### SpecSlot

Each command trains the selected configuration on eight GPUs and runs the
corresponding final evaluation. The launcher uses the paper's 120-epoch
ImageNet defaults. Replace `k2`/`k4` or `256`/`512` to select any of the four
released SpecSlot contracts.

```bash
# ImageNet-256
bash scripts/run_specslot.sh \
  /path/to/your/ImageNet /path/to/your/outputs 256 k2
bash scripts/run_specslot.sh \
  /path/to/your/ImageNet /path/to/your/outputs 256 k4

# ImageNet-512
bash scripts/run_specslot.sh \
  /path/to/your/ImageNet /path/to/your/outputs 512 k2
bash scripts/run_specslot.sh \
  /path/to/your/ImageNet /path/to/your/outputs 512 k4
```

### JiT baselines

```bash
# ImageNet-256
bash scripts/run_jit.sh \
  /path/to/your/ImageNet /path/to/your/outputs 256 b8
bash scripts/run_jit.sh \
  /path/to/your/ImageNet /path/to/your/outputs 256 b16

# ImageNet-512
bash scripts/run_jit.sh \
  /path/to/your/ImageNet /path/to/your/outputs 512 b16
bash scripts/run_jit.sh \
  /path/to/your/ImageNet /path/to/your/outputs 512 b32
```

# 📝 Text-to-image

Place the BLIP3o WebDataset mixture under one directory:

```text
/path/to/your/T2I/**/*.tar
```

The launcher uses the paper's 256px, 400-epoch protocol. Set `RESUME=auto` to
resume from `checkpoint-last.pth`; without it, the run starts from scratch.

```bash
# SpecSlot W256/K4/B1536
bash scripts/run_t2i_8gpu.sh \
  /path/to/your/T2I /path/to/your/t2i_runs/specslot-256 \
  specslot 256 64

# JiT-B/8
JIT_VARIANT=b8 bash scripts/run_t2i_8gpu.sh \
  /path/to/your/T2I /path/to/your/t2i_runs/jit-b8-256 \
  jit 256 64

# JiT-B/16
JIT_VARIANT=b16 bash scripts/run_t2i_8gpu.sh \
  /path/to/your/T2I /path/to/your/t2i_runs/jit-b16-256 \
  jit 256 64
```

## 📈 Evaluation during training

Prepare the official GenEval and DPG-Bench assets, then set
`EVAL_ASSETS_DIR` to their parent directory:

```bash
EVAL_INTERVAL=10 \
EVAL_ASSETS_DIR=/path/to/your/data/Eval \
EVAL_MAX_IMAGES=0 EVAL_DPG_MAX_PROMPTS=0 \
EVAL_NUM_SAMPLES=4 EVAL_DPG_SAMPLES=4 \
REQUIRE_EVAL_METRICS=1 \
bash scripts/run_t2i_8gpu.sh \
  /path/to/your/T2I /path/to/your/t2i_runs/specslot-256-eval \
  specslot 256 64
```

The evaluation run stores generated images, evaluator outputs, `metrics.json`,
and TensorBoard scalars under the run directory. Set `EVAL_MAX_IMAGES=0` and
`EVAL_DPG_MAX_PROMPTS=0` to use the complete official manifests.
